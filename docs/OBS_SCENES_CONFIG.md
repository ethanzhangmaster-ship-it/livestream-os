# OBS 场景配置示例

## 推荐场景结构

LivestreamOS 会根据观众注意力和意图自动切换场景。以下是推荐的场景配置。

## 场景列表

### 1. hook（开场钩子场景）

**用途**：直播开始、注意力下降时使用

**推荐内容**：
- 吸引眼球的视频片段
- 产品亮点预告
- 优惠信息展示
- 倒计时动画

**触发条件**：
- 直播开始
- 平均注意力 < 0.3
- 流失风险 > 0.6

**示例源配置**：
```
- 媒体源：开场视频.mp4
- 文本源：今日特惠
- 图像源：产品主图.png
```

---

### 2. narration（产品讲解场景）

**用途**：正常产品讲解、中等注意力

**推荐内容**：
- 主播讲解画面
- 产品细节展示
- 使用演示
- 功能介绍

**触发条件**：
- 中等注意力（0.3-0.7）
- 产品咨询意图
- 正常互动

**示例源配置**：
```
- 视频采集设备：摄像头
- 图像源：产品图片.png
- 文本源：产品名称、价格
- 浏览器源：产品详情页
```

---

### 3. stats（数据展示场景）

**用途**：高注意力、展示产品数据

**推荐内容**：
- 销量数据
- 用户评价
- 对比数据
- 专业测评

**触发条件**：
- 高注意力（> 0.7）
- 价格敏感意图
- 对比需求

**示例源配置**：
```
- 视频采集设备：摄像头
- 浏览器源：数据图表
- 文本源：销量数字
- 图像源：对比表格.png
```

---

### 4. cta（行动号召场景）

**用途**：购买信号、高转化概率

**推荐内容**：
- 购买链接
- 限时优惠
- 库存提示
- 购买引导

**触发条件**：
- 购买意愿强烈
- 高注意力 + 高互动
- 会话后期（> 30 分钟）

**示例源配置**：
```
- 视频采集设备：摄像头
- 文本源：立即购买、限时优惠
- 图像源：二维码.png
- 浏览器源：购买页面
```

---

### 5. qa（问答场景）

**用途**：观众提问、互动

**推荐内容**：
- 问答界面
- 常见问题列表
- 互动提示
- 客服信息

**触发条件**：
- 观众提问
- 产品咨询
- 疑虑解答

**示例源配置**：
```
- 视频采集设备：摄像头
- 文本源：观众问题
- 图像源：答案提示.png
- 浏览器源：FAQ 页面
```

---

### 6. idle（待机场景）

**用途**：无观众、低注意力

**推荐内容**：
- 静态画面
- 循环视频
- 等待提示
- 背景音乐

**触发条件**：
- 无观众
- 低注意力（< 0.2）
- 长时间无互动

**示例源配置**：
```
- 媒体源：循环视频.mp4
- 文本源：等待中...
- 图像源：品牌 Logo.png
```

## 场景切换流程

### 典型直播流程

```
开始直播
    ↓
hook（开场钩子）→ 吸引注意力
    ↓
narration（产品讲解）→ 正常讲解
    ↓
stats（数据展示）→ 高注意力时展示数据
    ↓
qa（问答）→ 回答观众问题
    ↓
cta（行动号召）→ 引导购买
    ↓
idle（待机）→ 等待新观众
    ↓
hook（重新吸引）→ 循环
```

## 场景命名规范

**重要**：场景名称必须与代码中的场景名称完全匹配。

### 正确命名

✅ `hook`
✅ `narration`
✅ `stats`
✅ `cta`
✅ `qa`
✅ `idle`

### 错误命名

❌ `Hook`（大写）
❌ `开场场景`（中文）
❌ `hook_scene`（多余后缀）
❌ `hook-1`（多余数字）

## 场景源配置建议

### 视频采集设备（摄像头）

**推荐设置**：
- 分辨率：1920x1080
- 帧率：30fps
- 编码器：硬件（NVENC/AMF）

### 文本源

**推荐设置**：
- 字体：思源黑体 / 微软雅黑
- 字号：48-72
- 颜色：白色 / 黄色
- 描边：黑色 2px

### 图像源

**推荐设置**：
- 格式：PNG（透明背景）
- 分辨率：匹配画布
- 位置：居中或指定位置

### 浏览器源

**推荐设置**：
- 宽度：1920
- 高度：1080
- FPS：30
- 自定义 CSS：根据需要调整

## 场景过渡特效

### 推荐过渡类型

1. **淡入淡出**：适合所有场景切换
2. **滑动**：适合内容相关场景
3. **缩放**：适合强调重点
4. **擦除**：适合快速切换

### 过渡时长

- **快速切换**：300-500ms
- **正常切换**：500-1000ms
- **慢速切换**：1000-2000ms

## 常见问题

### Q: 场景切换不生效？

**A:** 检查以下几点：
1. 场景名称是否完全匹配（区分大小写）
2. OBS 是否正在运行
3. WebSocket 连接是否正常
4. 查看 LivestreamOS 日志

### Q: 如何添加自定义场景？

**A:** 
1. 在 OBS 中创建新场景
2. 在代码中添加场景切换逻辑
3. 更新场景列表

### Q: 场景切换太频繁？

**A:** 
调整配置参数：
- 增加场景切换的最小间隔
- 提高注意力阈值
- 降低敏感度
