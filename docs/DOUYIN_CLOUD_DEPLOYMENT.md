# 抖音云部署指南

本文档说明如何将 Livestream OS 部署到抖音云服务。

## 抖音云优势

- **免域名备案**：使用内网专线，无需域名备案
- **免鉴权**：调用 OpenAPI 无需 access_token
- **低延迟**：内网专线，延迟降低 60%
- **高可靠**：失败率降低 90%
- **弹性扩缩容**：根据流量自动扩缩容

## 部署架构

```
┌─────────────────────────────────────────────────────────┐
│                    抖音云服务                             │
├─────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────┐  │
│  │  Livestream OS (容器服务)                        │  │\n│  │  - 端口 3000: 抖音回调（内网专线）              │  │\n│  │  - 端口 8080: 监控仪表板                        │  │\n│  └──────────────────────────────────────────────────┘  │\n│  ┌──────────────────────────────────────────────────┐  │\n│  │  抖音直播服务器                                  │  │\n│  │  - 通过内网专线推送直播数据                      │  │\n│  └──────────────────────────────────────────────────┘  │\n└─────────────────────────────────────────────────────────┘\n         │\n         │ 内网专线\n         ▼\n┌─────────────────────────────────────────────────────────┐\n│                    你的本地环境                          │\n├─────────────────────────────────────────────────────────┤\n│  OBS Studio (直播推流)                                  │\n│  - 端口 4455: OBS WebSocket                            │\n└─────────────────────────────────────────────────────────┘\n```\n\n## 部署步骤\n\n### 1. 准备工作\n\n**1.1 安装抖音云 CLI**\n\n```bash\n# 下载抖音云 CLI\n# 访问：https://developer.open-douyin.com/docs/resource/zh-CN/interaction/develop/douyincloud/guide\n\n# 登录抖音云\ndouyin-cloud login\n```\n\n**1.2 创建抖音云服务**\n\n1. 登录抖音开放平台控制台\n2. 进入「抖音云」服务\n3. 创建新服务\n   - 服务名称：livestream-os\n   - 服务类型：容器服务\n   - 运行环境：Node.js 18\n\n### 2. 配置环境变量\n\n在抖音云控制台配置环境变量：\n\n```env\n# OBS WebSocket 配置\nOBS_HOST=你的本地IP\nOBS_PORT=4455\nOBS_PASSWORD=your_obs_password\n\n# 抖音 API 配置（抖音云免鉴权）\nDOUYIN_API_KEY=aww36rpeq413jv0c\nDOUYIN_API_SECRET=c45716df69c2ed1e7a2093ee2ced4bf8\nDOUYIN_ROOM_ID=你的直播间ID\n\n# 数据模式\nUSE_FAKE_DATA=false\n\n# 监控配置\nDASHBOARD_PORT=8080\n\n# 日志级别\nLOG_LEVEL=info\n```\n\n**注意**：OBS_HOST 需要配置为你的本地 IP，抖音云会通过内网专线连接。\n\n### 3. 构建并上传镜像\n\n**3.1 构建 Docker 镜像**\n\n```bash\n# 在项目根目录\ndocker build -t livestream-os:latest .\n```\n\n**3.2 推送到抖音云镜像仓库**\n\n```bash\n# 登录抖音云镜像仓库\ndouyin-cloud docker login\n\n# 标记镜像\ndocker tag livestream-os:latest registry.douyin-cloud.com/your-namespace/livestream-os:latest\n\n# 推送镜像\ndocker push registry.douyin-cloud.com/your-namespace/livestream-os:latest\n```\n\n### 4. 部署服务\n\n**4.1 创建部署配置**\n\n创建 `douyin-cloud.yaml`:\n\n```yaml\napiVersion: v1\nkind: Service\nmetadata:\n  name: livestream-os\n  labels:\n    app: livestream-os\nspec:\n  ports:\n  - port: 3000\n    name: callback\n    protocol: TCP\n  - port: 8080\n    name: dashboard\n    protocol: TCP\n  selector:\n    app: livestream-os\n---\napiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: livestream-os\nspec:\n  replicas: 1\n  selector:\n    matchLabels:\n      app: livestream-os\n  template:\n    metadata:\n      labels:\n        app: livestream-os\n    spec:\n      containers:\n      - name: livestream-os\n        image: registry.douyin-cloud.com/your-namespace/livestream-os:latest\n        ports:\n        - containerPort: 3000\n        - containerPort: 8080\n        env:\n        - name: NODE_ENV\n          value: production\n        resources:\n          limits:\n            cpu: \"2\"\n            memory: \"2Gi\"\n          requests:\n            cpu: \"1\"\n            memory: \"1Gi\"\n        livenessProbe:\n          httpGet:\n            path: /health\n            port: 8080\n          initialDelaySeconds: 30\n          periodSeconds: 10\n        readinessProbe:\n          httpGet:\n            path: /health\n            port: 8080\n          initialDelaySeconds: 5\n          periodSeconds: 5\n```\n\n**4.2 部署到抖音云**\n\n```bash\ndouyin-cloud apply -f douyin-cloud.yaml\n```\n\n### 5. 配置回调地址\n\n**5.1 获取抖音云内网地址**\n\n```bash\n# 查看服务状态\ndouyin-cloud get service livestream-os\n\n# 输出示例：\n# NAME              TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)\n# livestream-os     ClusterIP   10.0.0.123      <none>        3000/TCP,8080/TCP\n```\n\n**5.2 在抖音开放平台配置回调地址**\n\n1. 进入你的应用详情页\n2. 点击「配置 webhook 请求网址及订阅事件」\n3. 填写内网回调地址：\n   ```\n   http://livestream-os.douyin-cloud.svc.cluster.local:3000/live_data_callback\n   ```\n   或者使用抖音云提供的域名：\n   ```\n   http://your-app-id.douyin-cloud.com/live_data_callback\n   ```\n\n**5.3 订阅事件**\n\n勾选以下事件：\n- ✓ 直播间评论（live_comment）\n- ✓ 直播间点赞（live_like）\n- ✓ 直播间礼物（live_gift）\n- ✓ 粉丝团事件（live_fansclub）\n\n### 6. 配置 OBS 连接\n\n由于 OBS 运行在本地，需要配置抖音云到本地的连接。\n\n**方案 A：使用抖音云内网专线**\n\n1. 在抖音云控制台配置内网专线\n2. 连接你的本地网络\n3. 配置 OBS_HOST 为本地内网 IP\n\n**方案 B：使用公网 IP**\n\n1. 确保本地有公网 IP\n2. 在路由器配置端口转发（4455 -> 本地 OBS）\n3. 配置 OBS_HOST 为公网 IP\n\n**方案 C：使用 Mock 渲染器（测试）**\n\n暂时不连接 OBS，使用 Mock 渲染器测试：\n\n```env\nUSE_FAKE_DATA=true\n```\n\n### 7. 验证部署\n\n**7.1 查看服务状态**\n\n```bash\ndouyin-cloud get pods\n\n# 输出示例：\n# NAME                              READY   STATUS    RESTARTS   AGE\n# livestream-os-xxxxxx-xxxx         1/1     Running   0          1m\n```\n\n**7.2 查看日志**\n\n```bash\ndouyin-cloud logs -f livestream-os-xxxxxx-xxxx\n```\n\n**7.3 测试回调**\n\n使用抖音云测试工具发送测试数据：\n\n1. 进入抖音开放平台控制台\n2. 选择你的应用\n3. 点击「测试工具」\n4. 选择「直播小玩法测试」\n5. 发送测试评论：\"这个产品多少钱？\"\n\n**7.4 查看监控**\n\n访问监控仪表板：\n```\nhttp://your-app-id.douyin-cloud.com:8080\n```\n\n## 配置应用包信息\n\n在抖音开放平台配置应用包信息：\n\n### Android 包名\n\n```\ncom.yourcompany.parrotfood\n```\n\n### iOS Bundle Grafana：\n```\nhttp://your-app-id.douyin-cloud.com:3001\n```\n\n### 设置告警\n\n在抖音云控制台配置告警规则：\n\n- CPU 使用率 > 80%\n- 内存使用率 > 80%\n- 服务响应时间 > 100ms\n- 错误率 > 1%\n\n## 更新服务\n\n### 更新代码\n\n```bash\n# 自动扩缩容\n\n创建 `hpa.yaml`:\n\n```yaml\napiVersion: autoscaling/v2\nkind: HorizontalPodAutoscaler\nmetadata:\n  name: livestream-os-hpa\nspec:\n  scaleTargetRef:\n    apiVersion: apps/v1\n    kind: averageUtilization: 70\n  - type: Resource\n    resource:\n      name: memory\n      target:\n        type: Utilization\n        averageUtilization: 80\n```\n\n```bash\ndouyin-cloud apply -f hpa.yaml\n```\n\n## 故障排查\n\n### 服务无法启动\n\n```bash\n# 查看 Pod 状态\ndouyin-cloud describe pod livestream-os-xxxxxx-xxxx\n\n# 查看日志\ndouyin-cloud logs livestream-os-xxxxxx-xxxx\n```\n\n### 回调失败\n\n1. 检查回调地址是否正确\n2. 检查服务是否正常运行\n3. 查看抖音开放平台的错误日志\n\n### OBS 连接失败\n\n1. 检查 OBS_HOST 配置\n2. 检查网络连接\n3. 检查防火墙设置\n\n## 成本优化\n\n### 使用 Spot 实例\n\n抖音云支持 Spot 实例，成本降低 60%：\n\n```yaml\nspec:\n  template:\n
